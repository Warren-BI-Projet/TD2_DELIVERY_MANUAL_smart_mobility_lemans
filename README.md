# TD2_DELIVERY_MANUAL_smart_mobility_lemans

## Smart Mobility Le Mans

Ce projet suit l'offre de transport planifiée du réseau SETRAM et son état en temps réel dans Le Mans Métropole. Un workflow récupère périodiquement les données GTFS statiques pour décrire les arrêts et les passages prévus ; un second collecte toutes les 15 minutes les retards et les alertes du réseau. Ces données alimentent un tableau de bord actualisé automatiquement.

**[Consulter le tableau de bord Smart Mobility Le Mans](https://warren-bi-projet.github.io/TD2_DELIVERY_MANUAL_smart_mobility_lemans/)**

Les données de population servent uniquement de proxy pour comparer l'offre planifiée entre communes : elles ne représentent pas la fréquentation réelle ni la demande de transport.
